# SRS Traceability Baseline v0.2 — DAY08 / GATE A

## 0. Purpose

Đây là requirement-to-roadmap baseline cho Gate A. Nó bao phủ **57 FR + 12 NFR + 10 AC = 79 requirement**. `DESIGNED` ở cột DAY08 chỉ có nghĩa requirement đã có mapping/owner/path downstream; nó không có nghĩa implementation hoặc validation đã hoàn thành.

## 1. Lifecycle Semantics

| Dimension | Meaning at DAY08 |
|---|---|
| Design mapping | `DESIGNED` = requirement đã được đặt vào architecture/roadmap/artifact path |
| Implementation | giữ trạng thái lịch sử; phần lớn feature implementation chưa bắt đầu |
| Validation | `NOT_VALIDATED` trừ khi một future validation day cung cấp evidence |
| Requirement-text freeze | `FROZEN` = text/source authoritative được khóa cho baseline v0.2 |
| Evidence status | independent from implementation; documented requirement ≠ site-verified behavior |

## 3. AC-10 Special Handling

AC-10 freezes the rule **pilot phải so với measured baseline và target chính thức phải được chốt trước pilot**. Gate A không đóng numeric target. `>=50%` remains a research target from PRD until evidence and pilot design justify a committed value.

## 5. Interpretation Rules

1. `FROZEN` requirement text does not freeze clinical thresholds.
2. `DESIGNED` does not mean code exists.
3. `VERIFIED_DOCUMENTED` evidence means authoritative documentation exists; it does not mean SITE_VERIFIED.
4. Any future conflict with SRS/PRD requires decision/change control.
5. Missing/unavailable metric must remain null + reason rather than 0.
6. MFCV remains optional/site-gated under FR-064.
7. Knee correction remains prohibited until DR-K gate is sufficient.
8. AC-10 cannot be marked validated from schedule progression alone.
