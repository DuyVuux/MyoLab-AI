# M2-R — QC Research Core Milestone

## Achieved capability
The project now has versioned ingestion/QC evidence semantics, deterministic window identity, six QC evidence families, data-integrity precedence, hierarchical aggregation, fail-closed metric handoff, research-only threshold provenance, physiology/domain challenge coverage, stratified error analysis, and reproducibility/property freeze.

## What is deliberately not claimed
- expert agreement or adjudicated reference;
- public-dataset QC accuracy;
- clinical/site effectiveness;
- validated poor-contact threshold;
- validated OOD model/score;
- autonomous diagnosis or finalization.

## Phase transition
M2-R permits DAY40 to define versioned preprocessing profiles. Processing must continue to respect DAY31 eligibility and the DAY39 frozen QC boundary.
