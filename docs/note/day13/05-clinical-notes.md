# Chốt product wording (Wording Lâm sàng)

4 kết luận kỹ thuật được phép sử dụng trong Day 13:

1. **supported_pattern:**
Quan sát thấy mẫu biến đổi tín hiệu đáp ứng rule kỹ thuật v0.1.

2. **no_supported_pattern:**
Chưa quan sát thấy mẫu biến đổi đáp ứng đầy đủ rule kỹ thuật v0.1.

3. **inconclusive:**
Bằng chứng kỹ thuật chưa nhất quán hoặc chưa đủ để tổng hợp.

4. **abstained:**
Dữ liệu không đủ điều kiện để tạo kết luận kỹ thuật.
