# Câu hỏi mở

- Canonical DOI/version chính xác là gì?
- Archive format thật là gì?
- Sampling rate/unit/channel order có ở metadata nào?
- Subject/session/repetition nằm ở path, file name hay table?
- Source gesture definitions có map được năm class Task A không?
- Dataset có đủ repetitions cho P1 personalization không?
