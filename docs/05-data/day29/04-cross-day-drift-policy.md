# Cross-day drift policy

## Mục đích

Mô tả mức độ thay đổi giữa ngày trong cùng subject/gesture/channel.

## Không được suy

- fatigue confirmed;
- electrode shift confirmed;
- physiological decline confirmed;
- model performance decline.

## Compatibility gate

Chỉ so sánh khi cùng:

- subject;
- canonical label;
- channel semantics;
- unit;
- preprocessing profile;
- feature definition/version.

## Minimum report

- số record mỗi ngày;
- median và MAD;
- ratio;
- robust shift score;
- missingness;
- limitation statement.
