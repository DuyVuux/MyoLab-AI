# SOP xác minh canonical source

## Input

- Trang record chính thức.
- DOI/repository ID.
- Version/revision.
- License page/file.

## Output

- `source-record.json` không placeholder.
- License snapshot + SHA-256.
- Citation và permitted-use decision.

## Fail closed

Không dùng mirror, blog hoặc tên dataset không gắn record ID làm SSOT. Access và reuse rights là hai trường khác nhau.
