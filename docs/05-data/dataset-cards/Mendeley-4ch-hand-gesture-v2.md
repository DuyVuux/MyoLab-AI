# Dataset Card — Mendeley 4-channel Hand Gesture v2

## Identity
- Dataset ID: `MENDELEY_4CH_HAND_GESTURE_V2`
- Repository: Mendeley Data
- DOI: `10.17632/ckwc76xr2z.2`
- License: **CC BY 4.0 — VERIFIED**

## Observed facts
The official record describes 4-channel forearm sEMG from 40 participants performing 10
hand/wrist gestures. The gesture list includes rest/neutral, wrist extension, wrist
flexion and grip. DAY33 records sampling rate as `NOT_VERIFIED_IN_DAY33` rather than
copying an assumption from secondary sources.

## Role
This is a compact external source useful for sparse-channel adapter and label-provenance
research. It is not a clinical cohort and is not equivalent to Noraxon acquisition.

## Governance
The raw payload is not committed. Downloaded files, if used later, must be hashed into an
external payload ledger before canonicalization.
