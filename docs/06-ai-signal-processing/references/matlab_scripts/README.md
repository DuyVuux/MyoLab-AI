# Thư mục lưu trữ MATLAB Code (Archived)

Thư mục này được sử dụng để lưu trữ mã nguồn MATLAB gốc từ các tài liệu/nghiên cứu (papers) trước đây (ví dụ: nghiên cứu của sếp). 

Mục đích:
- **Lưu trữ tài liệu (Archival):** Đóng vai trò là tài liệu tham khảo thuật toán (Reference).
- **Không thực thi trực tiếp:** Code ở đây sẽ không chạy trên môi trường production, mà chỉ dành cho Data Scientist / Engineer tham khảo để hiểu rõ logic khi cần viết lại sang pipeline Python.

**Cách sử dụng:**
Hãy đặt các tệp `.m`, `.mat`, hoặc tài liệu PDF paper liên quan vào thư mục này.
