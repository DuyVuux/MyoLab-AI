# Day 30 red-team checklist

- Can any missing or malformed input default to a GO decision?
- Can `training_allowed`, `pooled_training_allowed` or `test_set_opened` become true?
- Can a test, sealed-test or outer-test record be silently skipped instead of rejected?
- Can a test-like path be disguised under a validation partition?
- Can one subject or atomic group appear in multiple partitions?
- Can a window exceed its source record or omit source/split/mapping provenance?
- Can an unknown, ambiguous or protected label enter a supervised view?
- Can conflicting source-label mappings be accepted?
- Can CH4 be called broken/reference without evidence?
- Can U1-U4 enter the GRABMyo primary view?
- Can CH channels be anatomically mapped to F/W channels?
- Can global scaling or a single hard-coded PSD sampling rate be selected?
- Can non-finite signal values pass DC removal or resampling?
- Can the deliverable contain raw signal, model weights or the reference pack?
- Can cross-day observations be converted into fatigue labels?
