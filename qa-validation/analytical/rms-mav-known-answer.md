# RMS/MAV Known-Answer Verification v0.1
For x=[3,4], RMS=sqrt((9+16)/2)=sqrt(12.5). For x=[-3,4], MAV=(3+4)/2=3.5. Units propagate unchanged because both functions are homogeneous amplitude metrics. Any QC block, mask, non-finite sample, or missing DAY45 provenance returns null with reason rather than zero.
